# Fusion Studio 0.19.0-rc.1 — hackathon prerelease

Windows x64 portable build. Install Blender 5.2 separately, extract the complete ZIP into a writable folder, then run `win-unpacked/Fusion Studio.exe`. Keep the entire folder together. DAZ content libraries and model runtimes are supplied by users.

Runtime remains the certified November 3 `rc1c` candidate; November 4 distribution adds public documentation, both demo videos and sanitized evidence. It does not rebuild or alter application binaries. Packaged ASAR SHA-256: `49f10f486e9e118d73e8b1af3ef76c585ae0a399b2e9a1aa501e4b33ac5a12f8`. Source tag includes later documentation and release tooling; runtime provenance remains recorded separately.

Demonstrated scope includes Blender preserved/editable imports, supported DUF/DSF and exchange-format subsets, compatible presets, shared edit/history/save workflows, conversational model chat and authenticated localhost MCP. Frozen evidence records 1,191 default parallel passes, 47 native passes and 44 packaged import cases across 42 sources. Portable CI complements these installed-dependency gates.

Release assets include Windows ZIP, SHA-256 checksums, public audit, two-minute cinematic trailer and four-minute continuous workflow. Cinematic comes first in project README. Both films retain their own captions, source hashes and verification reports in repository.

Known limits remain explicit: advanced native shaders, DAZ HD/grafts/TriAx parity, strand hair, production cloth/portrait realism and universal lossless roundtrips are not certified. November 4 dragon appearance import exposes unsupported dependency errors that block its export/render; an empty-scene autosave failed validation in rehearsal. Continuous static-trunk workflow completes with zero glTF errors and one `NODE_SKINNED_MESH_WITHOUT_SKIN` warning. Cloud model providers remain unverified.

Public distribution excludes private source assets, user profiles, credentials, raw captures, machine inventories and private logs. Runtime files retain exact certified hashes; selected evidence replaces local profile prefixes with placeholders. Original local release and private evidence remain untouched. Original code is MIT-licensed; bundled third-party notices and CC0 asset provenance retain their own terms.

Public distribution audit and `SHA256SUMS.txt` are provided alongside downloads. Removing internal files cleans the current source tree; earlier Git commits retain their original contents.

See project README for setup, film links and full release/verification documentation. This is a prerelease for documented subsets, not a general native-format fidelity guarantee.
