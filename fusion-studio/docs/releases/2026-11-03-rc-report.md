## Demo and requirements

Keep complete `win-unpacked` folder; run `Fusion Studio.exe`. Installed Blender **5.2.0 LTS** required. Tested Windows x64, NVIDIA RTX 3080/OptiX and CPU native reference renders. CPU remains render fallback; model runtimes, keys and weights are user supplied. Package unsigned. Local secondary-monitor preference retained with single-monitor fallback.

1. Import BMW with preserved rendering; render using source camera, add sphere, render again, save/reopen. Images in `evidence/screenshots/bmw-native-*.png` demonstrate changed pixels.
2. Import working copy through editable mode; expand asset in Outliner, select carShell, press F to inspect body. Geometry is a working snapshot; native shader/instance appearance remains approximate.
3. Select local imported DAZ asset; import compatible pose/shape/material preset, review report, apply, undo/redo, save/reopen and export GLB. Follow local fixture CSV to reproduce exact assets; licenses remain local.
4. Models & Connections: save compatible API or Ollama profile, Test connection, chat, Cancel/Clear. Keys persist encrypted; conversation stays in memory and sends entered messages only.
5. Enable MCP, optionally allow scene edits, copy client configuration. Inspect scene, then pass returned projectId/revision to primitive_add, object_transform, undo and redo. Disable afterward.

## Limits

Certified demonstrated subsets only. Static USD/Alembic; native shaders, modifier authoring, simulation, instancing and other advanced Blender semantics limited in editable exchange. Rig/morph meshes with extra modifiers keep base topology; preserved mode evaluates appearance. DAZ HD/grafts/strand hair, general ERC/TriAx/dual-quaternion parity, production cloth/portrait realism, independent overlapping-clip selection and universal lossless roundtrips remain uncertified. Drape short-run preview can report unconverged/partial coverage. Chat is conversational; automatic scene agents and external MCP-server connections deferred.
