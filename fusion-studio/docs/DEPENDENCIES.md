# Dependency license tracking

The unreleased Character Creator adds **CC0 asset data**, not MakeHuman/MPFB application code. Geometry, targets, game-engine rig/weights and correspondence data come from `makehumancommunity/mpfb2` pinned at `3af0cd5a2ffba072e93a34e5f6f494fdc4813ddf`; the source `LICENSE.ASSETS.md`, per-file hashes, compressed runtime identity and CC0 notice are retained. The adapter, sparse evaluator and scalp interpolation are independently implemented Fusion code. See [character checkpoint and limits](progress/2026-10-23-character-creator.md) and `public/characters/makehuman-provenance.json`.

Selected skins are Bobby_03's adult female hairless texture from the [official skins01 CC0 catalog](https://static.makehumancommunity.org/assets/assetpacks/skins01.html) and Toigo's male bronze skin from the [official skins02 CC0 catalog](https://static.makehumancommunity.org/assets/assetpacks/skins02.html). `public/characters/skins/provenance.json` retains authors, archive/source/material/output hashes and tone-neutral/high-pass derivations. Tomáš Klecer's [official Hair Editor templates](https://static.makehumancommunity.org/assets/assetpacks/haireditor.html) provide CC0 authored hair/brow/lash/facial guides; source archive/blend hashes and extraction boundaries are in the runtime foundation's hair provenance. Only plain asset data was extracted; no asset scripts, drivers or geometry-node graphs were executed or copied as product code. The older Aksel source remains in the source cache but is no longer the default skin. Private Genesis/paid content is excluded from the public starter library and package.

The reusable-component adoption adds the official Khronos `gltf-validator` **2.0.0-dev.3.10**, Apache-2.0, without transitive npm dependencies. Its included `LICENSE` and `NOTICES` (including Dart notices) remain with the production package; SHA-256 notice hashes and registry integrity are recorded in the npm inventory/lockfile. The compiled package's actual version and unsupported extensions appear in each inspection report. See [adoption boundary](dependency-evaluations/gltf-validator.md). This adds validation to the existing scene/exchange path; no new geometry or vendor runtime is embedded.

Opt-in tangent export reuses the MikkTSpace JS/WASM module already present in pinned Three.js. [Its adoption record](dependency-evaluations/mikktspace.md) records the exact module hash, upstream license sources, implemented scope and remaining compiled-component notice review. This introduces no new npm or native dependency. Do not treat the current upstream Rust dependency list as proof of the bundled module's build provenance. Public distribution remains subject to the existing complete native/runtime notice review.

0.19.0 development adds [faer 0.24.4](https://docs.rs/faer/0.24.4/faer/sparse/linalg/cholesky/index.html), an MIT-licensed Rust numerical library, for sparse ordering and Cholesky factorization of Fusion's original cloth equations. Default faer features are disabled; only `std` and `sparse-linalg` are enabled, with sequential numerical work inside the cancellable private helper. No vendor runtime is involved. The locked native inventory now contains 88 crates, including build/target dependencies; 16 omit crate-root notices in their downloaded package. These omissions and compiler/runtime notices still require review before public distribution. Available shipped notices and checksums are retained under `docs/native-dependencies`. No 0.19 package or public distribution has been produced. The faer archive includes inherited BSD AMD/COLAMD/LAPACK and MPL 2.0 SVD notices; all are retained with the crate’s declared MIT metadata. Notice presence alone does not establish which upstream routines are linked into the native module.

0.8.0 adds an original Rust native module through napi-rs 2.16.17 (pinned for the Windows GNU dynamic-symbol build). `native/Cargo.lock` pins all crates. `python scripts/audit-native.py` records their declarations/checksums and copies available crate-root notices to `docs/native-dependencies`, which is packaged. Five crates omit root notice files; compiler/Rust standard-library runtime notices and those missing notices require a complete review before public distribution. No public distribution has been made. The private Rust/GCC/LLVM download directories are development-only and excluded. The final module imports only Windows system DLLs, not a separate vendor/Node DLL.

Regenerate with `node scripts/audit-dependencies.cjs`. The machine-readable inventory records the locked package versions, declared license expressions, installed status, and SHA-256 hashes of package-root license/notice files. Missing notices and declarations require review; an SPDX string alone is not redistribution clearance.

Runtime npm dependencies are Three.js (MIT), Lucide (ISC with included MIT notices for inherited icons), and the Khronos glTF Validator (Apache-2.0 with inherited notices). The desktop distribution includes Electron and its Chromium/Node/native dependencies and accompanying notices; npm metadata alone does not inventory every component inside those binaries. Vite, Playwright and electron-builder are development tools. Preserve required notices when packaging; review the generated inventory before any public release.

Installed Blender is an external processing dependency, not copied into this release. Its GPL terms and a future source-based integration decision are described in ADR 002, with the primary Blender license reference. Commercial programs, copied experimental runtimes and paid content libraries are excluded from the distribution. Local test outputs derived from the user's assets are ignored by git and not packaged.
