# Testing and evidence

Fusion separates portable source checks from Windows/native acceptance. A green portable CI job does not certify Blender, private fixtures, final rendering or native-format fidelity.

## Current evidence

- [0.19.0-rc.1 release report](releases/2026-11-03-rc-report.md): 1,191 default parallel tests, zero failures/skips; 47 native passes with two explicit opt-in diagnostics ignored; 44 packaged cases across 42 source files.
- [Live model/MCP verification](verification/2026-11-03-live-connections.json): actual local Phi-3 through Ollama and compatible API, profile restart, cancellation, missing-model error, and official MCP Inspector calls to all seven tools.
- [Recorded demo](demo/2026-11-03/README.md): current packaged app, original procedural fixtures, source hashes and actual edit/history/save/export checks.

## Portable checks

From `fusion-studio` after installing locked dependencies:

```powershell
npm ci --ignore-scripts
node scripts/check-repository.cjs
node --test tests/model-connections.test.cjs tests/scene-foundation.test.mjs tests/scene-units.test.mjs tests/deformation.test.mjs tests/formulas.test.mjs tests/sculpt.test.mjs tests/animation.test.mjs
```

This 82-test subset covers core scene/geometry behavior and deterministic HTTP adapter fixtures. CI uses Windows and Node.js 22. Repository checks validate curated public links, Git-index inclusion, license consistency, generated/private artifact exclusions and obvious credential patterns. They are bounded hygiene checks, not a complete secret or security audit.

## Full desktop release gates

Install Blender 5.2 and build matching native module. Prepare public starter assets as described in [overview](../../README.md) and [dependency records](DEPENDENCIES.md). Then:

```powershell
npm test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-native.ps1 -RunTests
npm run package
$env:FUSION_TEST_EXECUTABLE=(Resolve-Path 'release-hackathon-20261103-rc1-final/win-unpacked/Fusion Studio.exe').Path
node --test tests/packaged-smoke.cjs
node tests/package-audit.cjs
node tests/connections-ui.cjs
node tests/modeling-ui.cjs
node tests/native-scene-ui.cjs
```

The package audit checks archive paths, locked SDK versions, byte equality of runtime sources and current local display preference. If using a fresh checkout, create optional `window-placement.local.json` with `{ "display": "primary" }` before reproducing that machine-specific audit; it is ignored by Git. Directory package remains separate from earlier releases.

`tests/import-matrix.cjs` requires locally registered manifests under `test-output/rc-20261103`. Public fixtures come from [independent generator](../scripts/make-rc-fixtures.py); private DSON registrations come from [local registrar](../scripts/register-rc-dson.py). Original BMW files and licensed DAZ libraries are intentionally absent from Git. Use [result matrix and gate record](releases/2026-11-03-rc-report.md) for demonstrated coverage and fixture-specific tolerances. Never manufacture a green result when a required asset/host is missing.

## Live connections

Start installed Ollama with an already installed `phi3:mini` model. This project does not bundle or download weights. Install/run official Inspector once:

```powershell
npm exec --yes --package=@modelcontextprotocol/inspector -- mcp-inspector --cli --help
node scripts/verify-live-connections.cjs
```

Optional `FUSION_LIVE_MODEL`, `FUSION_LIVE_BASE_URL` and `FUSION_INSPECTOR_CLI` select existing local resources. Script accepts loopback Ollama URLs only, uses a fresh app data directory, and removes temporary Inspector bearer configuration. Results/logs stay in ignored `test-output/live-connections-*`. Cloud endpoints, other models and other protocols need separate verification.

## Recording

Use current packaged executable and source fixtures generated by [make-gallery-fixtures.py](../scripts/make-gallery-fixtures.py). Capture reads them without modification:

```powershell
node scripts/capture-rc-demo.cjs
python scripts/finish-rc-demo.py <capture-scratch-directory>
```

Local FFmpeg path is supplied through `FUSION_MEDIA_FFMPEG`; default uses existing ignored media tools. Capture requires live local Ollama, OptiX for demonstrated native render, and free MCP port 39157. Review final video, representative frames, credentials and provenance before committing media. Keep original release archive/fingerprints immutable; new documentation/live checks have their own records.
