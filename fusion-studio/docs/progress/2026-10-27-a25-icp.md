# 2026-10-27 — A25 scan registration (Kabsch + ICP)

## Landed

- `src/icp.js` — rigid registration for scan alignment: `kabsch` (Horn quaternion method with a Jacobi eigensolver for the 4×4 Horn matrix) recovering rotation+translation between corresponding point sets; point-to-point `icp` with nearest-neighbor pairing, optional `maxPairDistance` outlier gating, RMSE-reported convergence.
- `tests/icp.test.mjs` — 4/4: Kabsch recovers a known 37° rigid transform to 1e-9 elementwise; ICP aligns an unregistered 120-point cloud onto its 18°-rotated copy with RMSE < 1e-6 and max point error < 1e-4, converging before the iteration cap; noisy cloud with gross outliers fits to RMSE < 0.02 when gated (and measurably worse ungated — the gate is proven to help); identical clouds give the identity with zero error. One kernel fix during development: RMSE was averaged over ALL source points including rejected outliers (reported 2.27 for a correctly gated fit); it is now computed over gated pairs only, which is the actual ICP objective.
