# Fitted panel drafting and retained surface grading — 0.18.0

Verified as a local 0.18.0 release on October 16, 2026. Earlier releases remain unchanged. The full unified-excellence goal remains active.

## User-visible workflow

Clothing offers **Draft fitted shirt panels…** for an imported skinned body. Review five bind joints (neck, left/right upper arm and forearm), torso ease, sleeve length, particle distance and fitting clearance. **Create fitted working copy** makes a new six-panel short-sleeve garment, preserving existing objects. It drafts from the resolved neutral source shape, fits a temporary design surface, flattens panels through the installed Blender worker, reconstructs editable physical panels and drapes on the current evaluated skin. Fusion owns the complete UI and scene.

Source must use metres, Y up, front +Z, left arm +X and a supported A/T bind pose. The original generator measures closed triangle-plane torso and arm contours and rejects unusable sections or joint mappings. Defaults use fixed geometric torso levels, not anatomical tailoring landmarks. Joints are extracted from a private skeleton copy using inverse-bind positions and the constant bind matrix inverse; posing and root motion do not move the source landmarks.

The Pattern & Sewing Editor opens these physical source panels. Boundary/curve, hole, internal-line, dart, pin, partial-sewing, fabric, color and density edits remain authored data; Apply re-evaluates through the fitting reference and replaces the drape in one undo step. Placement, flips, panel addition/removal/duplication and the replacement template are unavailable for an attached reference. **Make independent flat working copy** supplies the unrestricted design path while preserving the fitted garment. New vertices may extend at most 50 mm from their retained UV patch; a panel cannot silently attach to another panel's fitting patch.

## Retained references and independent grading

The project stores version-1 fitted metadata: stable body identity, SHA-256 connectivity/count identity, original UV/3D reference triangles, panel ownership/offsets, native body attachments, reviewed joint mapping, source options, section profile and reconstruction diagnostics. Existing projects retain their old garment modes. Ordinary GLB/render exchange omits fitted metadata and body attachments, exporting the displayed garment. Paid body geometry and fixtures stay private.

Every update starts from authored flat panels and the retained design, never from a prior solved drape. Native barycentric attachments reconstruct the reference on the current neutral body and current posed skin. A panel-specific least-squares metric fit compares neutral reference edge-length changes in its grain coordinates. The positive symmetric square root of that metric grades its flat boundaries, controls, holes, internals and UV reference together. This supports directional scaling and shear without baking the previous evaluation. Separate torso girths/height guard the supported range; both global ratios and local principal stretches are bounded to 75–135%. Collapsed or ill-conditioned reference patches reject with a working-copy action.

An earlier single torso-ratio grader failed the independent 6%-width/3%-depth body-morph fixture at **60.04%** maximum local strain. The surface-metric version passes the same case at **28.11%**, 28.81° minimum angle, 0.01177 mm mean seam gap and zero measured body-face/inside/clearance violations. This is an original geometric grading approximation. Strong non-affine anatomical changes, new garment designs and untested bodies can still require redrafting.

Blender flattening uses typed numeric payloads, optional surface projection, Minimum Stretch with flip prevention, physical-area scaling and grain alignment. Results retain source vertex identities and reject UV splits, flips or invalid areas. Reconstruction preserves exact boundaries when budgets permit, otherwise fits cubics with a whole-interval error bound and synchronizes partial-seam cuts through exact subdivision. Holes, pins, internal anchors and dart references survive; dart dimensions explicitly require review. No proprietary pseudocode or installed-host code is incorporated.

## Transactions, cancellation and project stability

Drafting, flattening, reconstruction, binding, grading and draping share one scene-evaluation ticket and one history transaction. Project/object IDs, revision, request ID and input SHA accompany the installed-worker job. Failed/cancelled/stale work retains the previous consistent scene, selection and frame; native cancellation waits for helper exit. Preparation/meshing runs in disposable Web Workers with a 20-second limit. Fitted drapes explicitly use the bounded 120-second offline budget; ordinary geometry jobs retain their normal timeout. The UI describes this cost before drafting.

Save/reopen initially changed skin transforms because matrix decomposition altered slightly non-unit imported quaternions. Project snapshots now retain authored position/quaternion/scale values directly for automatically updated nodes. Manual matrices, including shear, remain matrices. Transform/rig deltas also materialize authored channels directly, avoiding decomposition and no-op history entries at later snapshot boundaries. Analytic repeated reload tests pass, and the detailed prepared simulation request matches exactly after reopening. The development desktop workflow re-drapes with zero displayed-coordinate difference after reload.

## Reproducing local acceptance

The detailed tests require the user's private Genesis integration fixture and installed Blender. Run desktop scripts serially. `npm test` covers the unit regression; `npm run test:surface-panels` covers typed physical flattening. Set `FUSION_TEST_EXECUTABLE` to the packaged executable, then run `tests/surface-drafting-ui.cjs`, `tests/surface-drafting-final.cjs`, `tests/pro-workflow.cjs` and `tests/packaged.cjs` with Node. `tests/surface-fit-performance.mjs` records the density sweep; `tests/bmw-render.cjs` verifies the supplied render fixtures. Package audit, release integrity and `scripts/verify_originals.ps1` must pass before `node scripts/record-release.cjs` records the local release manifest. The manifest contains numeric metadata only; scenes and rendered images remain private test outputs.
