# A12 subsurface scattering profile (2026-10-27)

Kernel: `src/sss.js`. Tests: `tests/sss.test.mjs` (3/3).

The normalized-diffusion SSS reflectance profile
`R(r) = (exp(-r/d) + exp(-r/(3d))) / (8π·d·r)`
(Christensen-Burley family) with per-channel scatter distances
(red travels farthest in skin-like media), a normalized discrete
blur kernel built from the profile, wrap diffuse for cheap SSS
terminator softening, and a thickness-attenuated translucency
term.

Independent oracles: Simpson integration of `R(r)·2πr` on a fine
grid reproduces the exact normalization (the two exponential
terms contribute 1/4 and 3/4) for three scatter distances; the
closed-form value at r = d matches; red outweighs blue at range
while the narrow channels dominate the 1/r core; every kernel
channel sums to exactly 1; wrap diffuse hits 1/3 at the
terminator for wrap 0.5 and reduces to Lambert at wrap 0;
translucency through one scatter distance is exactly e^(−1).
A sign-convention slip in the first translucency draft (to-light
vs light-travel direction) was caught by the tests and fixed to
the repo's light convention.

Limits: radial profile model only (no dipole/multipole
transport, no texture-space SSS blur pass, no thin-object
transmission maps).
