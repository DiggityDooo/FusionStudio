# A13 set driven keys / drivers — 2026-10-27

## Kernel

New `src/drivers.js`: a driver system over the safe expression engine
(`src/expressions.js`). Named properties are manual or driven;
drivers are expressions over other properties (manual or driven).

- Dependency-ordered evaluation via DFS over compiled-expression
  variable lists; declaration order does not matter.
- Cycles are reported with their path (`a -> b -> a`).
- Writing a driven property (via `setManual` or `addProperty`) is an
  explicit error until its driver is removed; removal restores manual
  control.
- `evaluate(overrides)` accepts transient inputs (e.g. frame time)
  that feed expressions without persisting as properties — verified
  by the unknown-variable error when the override is absent.
