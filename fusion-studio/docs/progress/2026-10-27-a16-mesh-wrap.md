# A16 mesh wrap / closest-point projection — 2026-10-27

## Kernel

New `src/mesh-wrap.js` — the deformation core of scan-to-template facial
topology wrapping (previously only the catch-all remaining-features stub
was cited):

- `closestPointOnTriangle`: Ericson's full region classification
  (face / 3 edges / 3 vertices) with barycentric coordinates.
- `closestPointOnMesh`: brute-force closest point + distance + triangle
  (a BVH can replace the search without changing semantics).
- `wrapMesh(template, target, {iterations, projection, smoothing})`:
  project-toward-surface + Laplacian relax iterations ending with a full
  projection pass, so the result lies on the target while keeping the
  template's topology, order, and count.

## Verified (tests/mesh-wrap.test.mjs, 4/4)

- Closest-point regions: interior hit with barycentric weights summing
  to 1, edge clamp, vertex clamp, hypotenuse clamp with zero opposite
  weight.
- Mesh closest point matches the analytic sphere distance within facet
  tolerance.
- A 5-radius sphere template wrapped onto a 3-radius sphere: final
  max/mean distance to the target mesh < 1e-6, indices identical, every
  vertex within facet sagitta (~0.021 for this tessellation) of the
  ideal radius — the test distinguishes mesh conformity (exact) from
  analytic-sphere agreement (sagitta-bounded).
- Plane-on-plane wrap is the identity; a plane draped over a sphere
  sags onto it (min z reaches the sphere top) with 1e-6 conformity.
