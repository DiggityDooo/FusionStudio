# A11 lens distortion model (2026-10-27)

Kernel: `src/lens.js`. Tests: `tests/lens.test.mjs` (3/3).

Brown-Conrady distortion on normalized image coordinates:
radial k1/k2/k3 plus tangential p1/p2, applied by
`distortPoint(s)` and inverted by `undistortPoint(s)` — Newton
iteration on the 2D residual (the first draft used fixed-point
iteration, which oscillates for strong pincushion coefficients;
Newton converges quadratically and the tests cover a strong
k1 = 0.35, k2 = 0.1 lens at the frame corners). Also the
companion post terms: vignette falloff (smoothstep ramp between
start/end radii) and per-channel radial scaling for chromatic
aberration.

Oracles: hand-computed model values at axis/diagonal points for
each coefficient family (including the p1 terms at (1,0) and
(0,1)); distort→undistort round trips recover an 81-point frame
grid and strong-lens corners to 1e-8; vignette hits its exact
ramp values (untouched center, half strength at the ramp
midpoint, 1 − strength past the end); aberration channels scale
exactly about the center.

Incident and restoration (recorded honestly): a Brown-Conrady
kernel already existed at this path from an earlier session
(registered mid-list, 4 tests, documented in
`2026-10-27-a21-lens-stabilization.md`) and this slice's first
draft overwrote both files before the collision was noticed
(the suite count dropping 859 → 858 exposed it; nothing in the
repo imported the old module, and the full suite stayed green).
The original also carried image-warp resampling and 2D
Procrustes similarity estimation; both are restored here in
equivalent form — `warpImageBuffer` over compositor RGBA
buffers (identity warp bit-exact; distort→undistort restores a
linear-ramp image, which bilinear resampling reproduces
exactly) and `estimateSimilarity2D` (recovers known similarity
transforms to 1e-9). Track stabilization from the original
module's scope lives in `src/stabilize.js`. The restored test
file carries 5 tests, a superset of the original 4 areas.
Process fix adopted for all later slices: check a target file
does not exist before writing a new kernel/test at its path.

Limits: normalized-coordinate model only (pixel conversion and
resampling are the caller's), no fisheye/omnidirectional
models, no lens calibration from observations.
