# Safer dependencies and verified rotation drivers — 0.13.0

## Behavior and fidelity

**Compatible:** supported DSON scalar dependencies and verified unit-scale rotation outputs now drive the imported figure in Fusion. The owned Genesis fixture retains 20 formulas, 137 verified joint frames and 16 driven joints. Its eye focal-point control changes each eye by 3°. Forearm controls feed twist joints. Correctives and garment collision use the evaluated skeleton. This is public-format compatibility with general linear skinning, not measured native DAZ deformation parity, HD, graft or shader parity.

**Inspired:** Character shaping has a Dependencies inspector with authored/evaluated values, searchable outputs/bindings, verified-frame counts, constraint passes and actionable diagnostics. Pause/resume retains original rules and shares one recoverable edit with dependent garments. Authored FK, saved poses and animation keys remain separate from driven offsets. Repeated evaluation, undo/redo and project reload do not repeatedly bake drivers into the authored pose.

The evaluator follows the public [DSON formula](https://docs.daz3d.com/public/dson_spec/object_definitions/formula/start) and [operation](https://docs.daz3d.com/public/dson_spec/object_definitions/operation/start) descriptions for scalar RPN arithmetic, constant/linear/TCB splines and sum/multiply stages. The importer records explicit aliases only after resolving the actual local asset file. Different file-qualified controls remain distinct; ambiguous fragments, unresolved dependencies, unsupported operations and cycles produce reports instead of guessing or running code. No vendor pseudocode or private asset is in the implementation or package.

## Consistency, export and limits

Verified source/rest/axis frames convert source rotations to joint quaternions. Authored XYZ limits project results and propagate bounded channels downstream, with a maximum of 32 dependency passes. The fixture's hip frame is unverified and remains manual. Unit-scale/source-frame mismatch, translation/scale/material outputs, pose-corrective-to-rotation feedback/chains and conflicting enabled IK remain outside the supported binding scope. Unknown outputs are visible compatibility warnings; invalid mathematics blocks deformation. Pausing imported drivers leaves independent morph/FK tools available.

Evaluation limits are 16,384 channels, 4,096 formulas, 512 operations per formula, 131,072 total operations, 24,576 graph nodes, stack depth 256, 128 spline knots, 2,048 rotation frames and 2,048 authored correctives. Unsupported or nonconvergent cases do not partially commit rotations/morphs. Playback restores transforms, control values, morphs, IK and cached authored pose on failure and stops; failed export restores the pose, frame and mixer flags. Incoming malformed pose caches fail before replacing the current scene. IK preview restores failed edits and asks to pause conflicting imported drivers or use a separate chain.

Fusion projects retain editable formulas, aliases and authored pose caches under schema 2. Existing projects load; old imports lacking verified source frames need a new editable DSON import for rotation binding. No guessed metadata migration is applied. Standard exchange warns that character drivers become evaluated motion, samples motion, and excludes the editable graph/frame caches. Reimporting that exchange does not double-apply drivers; live morphs remain available. The Blender bridge now explicitly exports the current pose rather than its glTF exporter's default rest pose.
