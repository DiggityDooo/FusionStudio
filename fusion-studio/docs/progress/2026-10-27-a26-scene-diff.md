# A26/A28 scene diff and patch (2026-10-27)

Kernel: `src/scene-diff.js`. Tests: `tests/scene-diff.test.mjs`
(3/3). Evidence added for `A26 Version control integration`
and `A28 Project/workspace management`.

Structural diff between scene documents (plain JSON-shaped
data) as a JSON-serializable, invertible patch — the merge core
a version-control or collaboration layer needs. Objects diff
per key; equal-length plain arrays diff element-wise; arrays of
id-keyed objects match by id, address elements with `{ id }`
path segments, and record element indices so removals and
additions restore exact positions in both directions; reordered
shared elements fall back to a wholesale array set (order is
meaningful in hierarchies). Every op carries `previous`, so
`invertPatch` undoes a patch exactly, and `applyPatch` never
mutates its input.

Oracles: an 8-op realistic scene edit (value changes, an object
removal and addition, a settings change) round-trips forward,
through JSON, and backward; surgical single-coordinate edits
stay single ops; no-op diffs are empty; malformed patches throw.

Limits: whole-scene structural diff (no three-way merge or
conflict UI), arrays without ids that change length are
replaced wholesale, non-JSON values (functions, class
instances) are out of scope by design.
