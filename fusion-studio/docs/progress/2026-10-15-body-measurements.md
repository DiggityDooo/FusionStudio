# Source-shape torso measurements — 0.16.0

The Character workspace now includes **Body Measurements → Inspect torso cross-sections** for imported skinned bodies. Review hips, waist and chest at adjustable percentages of source height. The dialog shows actual surface girths, width/depth, section heights and an X/Z contour preview. Save records a reviewed snapshot in the Fusion project. Refresh after shaping; a stored snapshot does not assert that it still matches the current body. Current garment grading and solver behavior are unchanged.

## Original implementation and limits

Triangles are intersected with horizontal source-space planes. A spatial grid welds material/UV-split endpoints at one micrometre; adjacency traces closed loops. The single loop enclosing the source center supplies each girth. Separate closed limb contours are excluded. Open, branched, ambiguous, coincident, crossing or overly complex sections report a problem rather than inventing a closed hull. Coincident planes get one reported 0.1 mm shift. These checks establish section usability, not global body watertightness or an anatomical landmark.

Dependencies are evaluated on a private skeleton copy with preserved source identities. Current resolved morphs and active correctives are included; bone posing is excluded when reading vertices. Inspection cannot initialize caches, change morphs or move bones in the authoritative document. Source Y must be upright; yaw/translation and positive uniform scale are supported, while reflection, shear and nonuniform scale are rejected. Dimensions are source-local metres; world scale is separately reported. Static accessories are excluded; isolate a visible skinned body from overlapping clothing before measuring.

Limits: 1.2–2.2 m source height, 45–85% ordered hips/waist/chest planes, 200,000 triangles, 500,000 source vertices, 50,000 section intersection points and 4,096 points per closed contour. A dedicated worker traces sections after 180 ms debounce, with a 10-second timeout. New previews terminate earlier workers; closing or Escape terminates pending work. Scene identity, revision/input hash and per-preview IDs prevent stale saves. Source extraction remains synchronous but is bounded; it measured approximately 11 ms on the inspected Genesis session.

Saved metadata is validated before project replacement. One small metadata history entry stores each save; undo/redo preserves the current frame, geometry objects and unrelated character state. Mixed delta/snapshot history materializes these fields across later edits, removals, branch truncation and resets. Ordinary GLB exchange omits the snapshot; the Fusion project retains it. This is **Inspired** geometry inspection, not DAZ/CC/MD measurement parity or a medical tool.

## Fit remains unfinished

A direct measurement warp closed seams but worsened distortion/body crossings, so it was removed. An uncalibrated 60-frame installed-Blender cloth trial with full body geometry and a flat rest shape also failed the seam/strain gate; no improved-quality mode is exposed. Numeric conditions and limits are recorded in `research/garment-fit-2026-10-15.md`; generated meshes and scripts remain private under ignored `test-output/`.

Next work is fit-aware drafting/grading and pose-aware sleeve placement using the measured source sections, followed by renewed seam, strain, clearance and face-contact gates. Robust layered/animated contact, calibrated fabric and finer drape budgets remain required, followed by deeper modeling/sculpt/UV, render/sequence controls, broader character authoring and interchange. The full unified-excellence goal is active and incomplete.
