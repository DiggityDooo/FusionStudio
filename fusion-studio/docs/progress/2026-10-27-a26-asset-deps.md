# A26 asset dependency graph + path relinking — 2026-10-27

## Kernel

New `src/asset-deps.js`, lexical only (no filesystem access, identical
results on any platform):

- Path algebra: `normalizeAssetPath` (forward-slash canonical form,
  dot-segment resolution, drive letters, root escape prevention),
  `resolveAssetPath`, `relativeAssetPath`, `assetDirname`.
- `createDependencyGraph(edges)`: topological `loadOrder` (dependencies
  first, deterministic sorted-ready Kahn), `findCycle` (returns the
  actual cycle path), `affectedBy` (transitive reverse reachability —
  change impact), `closureOf`, `leafDependencies` (external inputs),
  `missingDependencies(available)`.
- `packageAssets(graph, root)`: the root's closure in load order.
- `relinkAssets(missing, available)`: basename index matching
  (case-insensitive); unique matches relink, duplicates report
  `ambiguous` with candidates instead of guessing, unknown stays
  `missing`.

## Verified (tests/asset-deps.test.mjs, 5/5)

- Normalization: backslashes, duplicate slashes, `.`/`..`, drive
  letters, and root-escape cases all canonical.
- Resolve/relativize round-trips exactly; cross-drive paths stay
  absolute.
- Diamond graph: deps precede dependents in load order; impact of a
  texture change is exactly its transitive dependents; packaging a
  character yields its closure in load order.
- A 3-cycle is reported as a closed path and blocks load order with a
  descriptive error.
- Relinking: unique basename relinks across directory moves, two
  same-named files report ambiguity with both candidates, unknown files
  stay missing.
