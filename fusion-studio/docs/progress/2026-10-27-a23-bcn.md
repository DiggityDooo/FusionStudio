# A23 BCn texture compression — 2026-10-27

## Kernel

New `src/bcn.js`: BC1/BC3 (DXT1/DXT5) block compression with the
exact hardware byte layout — BC1 blocks are 8 bytes (two RGB565
endpoints + 32-bit index word), BC3 blocks are 16 (8-byte alpha block
with 3-bit indices + BC1 color block).

- Endpoint selection is min/max per channel quantized to RGB565;
  indices pick the nearest palette color (squared distance).
- BC1 honors the format's two modes: `c0 > c1` four-color palette, and
  the three-color + transparent palette when any texel has alpha <
  128.
- BC3 alpha uses the 8-value interpolated palette with exact endpoint
  reproduction.
- Whole-texture encode/decode pads edge blocks by clamping and crops
  back to the true dimensions.

## Verified (tests/bcn.test.mjs, 6/6)

Hand-checkable byte layout (white/black block → `0xFFFF`/`0x0000`
endpoints, exact decoded halves); solid color within RGB565
quantization bounds; transparent texels decode to alpha 0 in BC1
3-color mode; BC3 alpha ramp within one palette step with exact
extremes; a 16×16 gradient round-trip with max channel error ≤ 48 and
mean < 8; non-multiple-of-4 image (6×5) padding and size accounting.
