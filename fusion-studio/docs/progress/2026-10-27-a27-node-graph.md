# A27 node-graph evaluator — 2026-10-27

## Kernel

New `src/node-graph.js`: a generic value/dataflow graph evaluator, the
visual-programming substrate distinct from `geometry-nodes.js` (which
operates on meshes for A4).

- Node types are registered per graph instance with input sockets
  (with defaults), output sockets, params (with defaults), and an
  evaluate function. Built-ins: `const`, `add/sub/mul/div/min/max`,
  `clamp`, `mix`, `select`, and an `expression` node (any-named inputs,
  evaluated through `src/expressions.js`).
- `connect` validates sockets, and one link per input replaces the
  previous one (standard node-editor behavior).
- `evaluate()` walks the graph in topological order with per-call
  memoization (shared upstream nodes compute once), returns every
  node's outputs, and reports cycles with their full path
  (`n0 -> n2 -> n0`).
- Missing node output production, unknown types/sockets/params, and
  ghost node references are explicit errors.

## Verified (tests/node-graph.test.mjs, 6/6)

An end-to-end procedural bounce graph
(`mix(0.2, 2, |sin(3t)|)` clamped at 1.5) matches the closed-form value
to 1e-12; diamond dependencies evaluate exactly once per pass and
recompute on the next; socket defaults and link replacement; cycle
detection with path; custom `remap` node type with param edits taking
effect; `select` gating; and the full validation error surface.
