# A27 event bus — 2026-10-27

## Kernel

New `src/events.js`: an instance-scoped event bus for scene/tool
callbacks (A27 "Event handlers and callbacks").

- `on(event, handler, {priority, once})` returns an unsubscribe
  function; `once`, `off`, `clear`, `listenerCount` round out the API.
- Handlers run in priority order (higher first, then registration
  order), synchronously via `emit` or sequentially awaited via
  `emitAsync`.
- Error isolation: a throwing handler leaves an `undefined` slot in
  `results` and an entry in `errors`; later handlers still run.
- Wildcard `'*'` handlers receive every event as `(eventName, payload)`
  and are not double-invoked when `'*'` itself is emitted.
- Buses are fully independent instances — no global state, safe for
  headless batch runs and tests.

## Verified (tests/events.test.mjs, 7/7)

Priority + registration ordering, payload/result collection, once
semantics, unsubscribe and bulk `off`, throwing-handler isolation with
step-accurate error records, wildcard observation without double
invocation, sequential async emission despite a slow first handler,
bus independence, clear/count behavior, and handler validation.
