# A24 DXF laser/vector export (2026-10-27)

Kernel: `src/dxf.js`. Tests: `tests/dxf.test.mjs` (3/3).

ASCII DXF (R2000 group codes) for laser cutting and vector
workflows: `writeDxf` serializes LINE, LWPOLYLINE, CIRCLE, ARC,
and POINT entities with layers into a structurally valid file
(HEADER with $ACADVER, a LAYER table covering every used layer,
ENTITIES, EOF; coordinates at 6-decimal precision), and
`parseDxf` reads entities back, skipping unknown entity types
and foreign sections. `polylinesToDxf` bridges 2D contours
(e.g. from `src/mesh-section.js`) into cut layers.

Oracles: write→parse round-trips a five-entity job exactly
(entity types, layers, geometry, closed flags); the file's
group-code lines pair evenly and the layer table contains every
used layer; 1/3-style coordinates survive at format precision;
a hand-written foreign DXF with a SPLINE is parsed for its LINE
only; validation rejects splines, zero radii, and one-point
polylines.

Limits: 2D entities only (no 3DFACE/solids/blocks/dimensions),
LWPOLYLINE without bulges (arcs are separate ARC entities), no
binary DXF.
