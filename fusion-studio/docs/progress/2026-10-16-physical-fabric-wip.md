# Physical fabric response — development checkpoint

The delivered application remains **0.18.0**. Source is now **0.19.0, unreleased**. This work adds original SI material response and a controlled material test inside the existing Clothing workspace. The full unified-excellence goal remains active.

## Implemented behavior

- Optional surface material response with areal mass, separate warp/weft/shear stiffness, signed-dihedral bending, boundary-length-integrated sewing and timestep-based damping. Nominal studies are editable examples, explicitly uncalibrated.
- A coupled matrix-free Gauss–Newton solve with preconditioned conjugate gradients and an energy line search. The closed-seam limit uses a full three-component spring Hessian. Existing preview calculations retain their previous path and parameters.
- Clothing → Fabric response exposes physical values, solve accuracy/duration, read-only known-load strip testing and a measured/reference plot. Apply re-drapes in one transaction. Undo, project storage, cancellation and failure rollback preserve the prior scene. Returning to the existing preview restores its settings and exact tested geometry.
- Physical metrics include area/mass, membrane/bending/seam/kinetic energies, maximum speed, directional strain and linear residuals. Force residuals explicitly exclude contact reactions. Body-triangle friction uses a normal-correction bound; proxy and layered contact remain approximate.
- Metre-scale grain coordinates follow uniform root scale. Invalid material values, mismatched rest/grain metrics, duplicate pins, malformed loads and excessive work are rejected.

## Follow-up: coupled face support and accurate sparse solving

The largest remaining motion was traced to geometric body/cloth-face recovery forcing distant free vertices through the material coupling. Original retained, local barycentric face supports now contribute unilateral penalty energy to the same Gauss–Newton solve as the fabric. Supports are pruned as the cloth leaves the body feature; geometric recovery remains a fallback. Contact discovery is bounded to 24,000 retained planes. Final-step diagnostic vectors distinguish material motion, body corrections, face recovery and self contact. This is still an approximate body-contact model, not a general layered-cloth solver.

Fusion now assembles a constrained sparse system and uses MIT-licensed **faer 0.24.4** for ordering/Cholesky factorization. Symbolic analysis and numerical workspaces are reused within a drape job. Automatic mode selects sparse solving within a 12,000-vertex / 1.5-million matrix-entry limit and a 512 MiB estimated numerical factor/workspace budget; larger cases explicitly report PCG fallback. Explicit sparse requests reject outside these limits. Numerical failure rejects the dependent scene transaction. PCG remains available, with a 4–512 iteration bound. Body-face contact penalty, solver choice and actual backend/workspace are exposed in the same Clothing workspace. Original previews stay on their previous path.
