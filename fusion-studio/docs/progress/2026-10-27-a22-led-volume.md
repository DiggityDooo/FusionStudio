# A22 LED volume / in-camera VFX projection — 2026-10-27

## Kernel

New `src/led-volume.js`: generalized off-axis perspective (Kooima)
for rendering from a tracked eye through a physical screen rectangle.

- `offAxisFrustum({pa, pb, pc, eye, near, far})` returns view +
  projection matrices, the frustum bounds, and screen normal. The
  screen is one-sided: an eye behind it (or backwards corner winding)
  is an explicit error — an earlier forgiving normal-flip hid that
  case and was removed.
- `projectPoint`, `multiplyMat4`, and an `ledWallSetup` helper for a
  flat wall on z=0.

## Verified (tests/led-volume.test.mjs, 5/5)

The defining property: all four screen corners project exactly to
the NDC cube corners (±1, ±1) for four different eye positions, and
for a Y-rotated wall. A centered eye yields a symmetric frustum; a
lateral eye shears it without changing its width class. Parallax is
verified against an independent ray-pierce computation (background
point shifts to wall x=1.64 → NDC +0.41 when the eye moves right);
wall-locked points are eye-independent in screen space while depth
correctly varies; near/far planes map to NDC −1/+1.
