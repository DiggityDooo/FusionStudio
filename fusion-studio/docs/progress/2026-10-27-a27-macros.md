# A27 macro recorder + history authoring — 2026-10-27

## Kernel

New `src/macros.js`: records an ordered list of tool invocations (name,
JSON-safe params, timestamp) and replays them deterministically through
a caller-supplied executor. Replay never executes code — the executor
interprets step names, so macros are safe to store in scene files.

- `createMacro(name)`: `record`, `steps`, `setParams` (history
  re-authoring), `deleteStep`, `moveStep`, `truncate`, `clear`,
  `replay(executor, {overrides, from, to})`, `asFunction`, `toJSON`.
- Recorded params are deep-cloned on record and on replay, so later
  caller edits cannot rewrite history.
- Replay overrides by step index or by tool name; ranged replay
  (`from`/`to`) supports partial re-runs and batch processing.
- Executor errors are tagged with `stepIndex`/`stepName` and stop the
  replay at the failing step.
- `macroFromJSON` (validated `fusion-macro` documents) and
  `concatMacros` for history splicing.

## Verified (tests/macros.test.mjs, 6/6)

Record+replay reproduces an identical scene on a fresh rig; param
deep-clone isolation; edit/delete/reorder/truncate re-authoring with
exact replayed sizes; index- and name-keyed overrides; ranged replay;
error tagging with no steps running after a failure; JSON round-trip,
concatenation order, and input validation errors.
